# Strbuf

[![CC BY SA 4.0](https://img.shields.io/github/license/XUPTLinuxGroup2020/Favorites?style=flat-square)](https://creativecommons.org/licenses/by-sa/4.0/)

本仓库存放 XiyouLinuxGroup 成员在学习阶段完成的 Strbuf 练习项目。

本项目通常由当年的大一成员完成代码实现，并由大二成员负责审核与验收。

---

## 本地测试

详见 [StrbufTest](./StrbufTest/README.md)

所有代码必须先在本地通过所有测试

---

## 参与方式

请按照以下方式提交你的代码：

### 1. fork 本仓库  
在你的 fork 仓库中完成并提交代码，通过 Pull Request 将修改贡献至主仓库。

---

## 提交代码规则

所有成员的代码统一存放于仓库根目录下的：

```
submissions/
```

目录中。

---

## 源文件提交示例

命名方式：

使用大驼峰命名法（UpperCamelCase）的姓名拼音全拼，并以 `.c` 结尾。

将该文件直接放置在 `submissions/` 目录下。

示例（张三提交 main.c，应命名为 ZhangSan.c）：

```
strbuf
├── LICENSE
├── README.md
├── submissions
│   ├── README.md
│   └── ZhangSan.c
└── StrbufTest
```

代码提交详情以及多文件提交方式请阅读 `submissions/README.md`

---

## 审核流程

提交的 Pull Request 将由大二成员进行审核与反馈，审核通过后合并至主分支。
